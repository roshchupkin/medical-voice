Access token generator

Creates the anonymous token for a clinician's username + password, using the exact same derivation as the login screen.

Admin tool — run it locally only. Do not deploy the tools/ folder to the shared workstation, and generate tokens on a trusted machine.

Token (paste into js/config.js → APPROVED_ACCESS_TOKENS)


      
If this token is already in the list, these credentials are valid. The clinician's data is keyed to the username — changing either username or password later means old encrypted data cannot be decrypted.
